Snake Game (CAMLIV)

About the game

  • The game is a gesture-controlled version of the classic Snake game, where the snake moves up, down, left, and right based on live predictions from a custom machine learning model.
  • A webcam feed captures the players movements, MobileNet extracts visual features, and a lightweight neural network predicts which gesture the player is performing.
  • The same browser platform (CAMLIV) also lets users create and train their own gesture models, then plug those models directly into the Snake game for interactive testing.
  • Everything runs locally in the browser, which keeps latency low and ensures that webcam images are not sent to any external server.

How to use the project

  • As an educational tool, the project demonstrates end-to-end machine learning: data collection, training, live inference, and deployment into a real game.
  • As a portfolio piece, it showcases skills in front-end development (HTML/CSS/JS), TensorFlow.js integration, real-time webcam processing, and user-centric interaction design.
  • It can be used in classrooms, workshops, or demos to explain concepts like feature extraction, transfer learning, and real-time prediction in a hands-on, visual way.

Instructions: training your gesture model

  1. Launch CAMLIV
      2. Open the main CAMLIVE page, which shows buttons for Custom Model, Import Model, and Snake Game.

  2. Open the Custom Model module
      3. Click “Custom Model” to enter the interface where you can create and train a new model with your webcam.

  3. Allow camera access
      4. When prompted, grant webcam permission so the live video feed appears on the page.

  4. Define gesture classes
      5. Add class names that you will use to control the snake, such as Up, Down, Left, and Right.

  5. Capture training samples
      6. For each class, perform the corresponding hand gesture in front of the camera and capture 30-50 sample images per gesture, varying angle, position, and lighting for better robustness.

  6. Train the model
      7. Start training; CAMLIV uses MobileNet as a feature extractor and a dense neural network classifier trained in-browser with the Adam optimizer and categorical cross-entropy loss.

  7. Test live predictions
      8. After training, switch to live prediction mode and check if your gestures are correctly recognized with high confidence. If accuracy is low, collect more samples and retrain.

  8. Save the trained model (optional)
      9. Export the model and label files to your device so you can reload them later using the Import Model option.

Instructions: playing the Snake game

  1. Load or create a model
      2. Either use the model you just trained or go to “Import Model” to load a previously saved TensorFlow.js model and its label file.

  2. Open the Snake Game
      3. From the main page, click “Snake Game” to launch the gesture-controlled Snake interface.

  3. Enable webcam and model
      4. Make sure the camera is toggled on and the trained model is loaded so the game can read real-time predictions from your gestures.

  4. Map gestures to directions
      5. Use the same gestures you trained (e.g., a specific hand pose for up, another for left) to steer the snake in the game. The models predicted class is translated into movement commands.

  5. Play the game
      6. Try to eat as many food items as possible without hitting the walls or the snake's own body, while observing how model accuracy and latency affect control smoothness.

  6. Refine control
      7. If the snake does not respond reliably, adjust your gestures, improve lighting, collect more samples per class, and retrain the model for better prediction stability.

Best practices for players

  • Use clear, distinct gestures for each direction to help the model differentiate classes.
  • Play in a well-lit environment with a relatively plain background to reduce noise in the webcam input.
  • Keep your hand within the camera's field of view and at a consistent distance from the lens for smoother control.
